# 内置语料目录

把公版书 / 已授权书稿放在本目录，系统会在启动自举与 worker 增量巡检中自动入库
（间隔由 `CORPUS_WATCH_SECONDS` 控制，生产默认 1800 秒，开发栈默认 300 秒）。

## 文件要求

- 格式：`.txt`（UTF-8）或 `.md`；单文件 ≤ 20 MB，≤ 500 万字。
- 命名：`书名-作者.txt` 或 `书名--作者.txt`，例如 `小王子-圣埃克苏佩里.txt`。
  文件名无法解析时，会退化为「书名=文件名、作者=佚名」。
- 章节：以 `第X章 标题` / `第X回` / `Chapter N` / `## 标题` 开头识别章节；
  无章节标记时自动按约 6000 字切分为伪章节。

## 入库行为

1. 计算文件 `sha256`，与 `books.content_hash` 比对；未变化则跳过（幂等）。
2. 章节切分 → 语义切片（约 512 token / 80 token 重叠）→ 在线 Embedding → Qdrant + MySQL 切片镜像。
3. 重复入库按 `(book_id, chunk_no)` 更新，不会产生重复向量点。
4. 只读不改文件；删除文件不会删除已入库数据（需管理员在后台归档）。

## 版权说明

默认只收录**公有领域**作品（作者逝世满 50 年 / 明确进入公有领域）或你已获得授权的书稿。
内置 12 本书目不附正文，正文由你放入本目录后自动补齐。

#### 2.4 腾讯云服务器（**项目完成后再提供**）

| 项 | 要求 |

| 访问 | SSH host/port/user（密钥方式）、sudo 权限（或由你执行命令） |

## 7. 验收方式

- 我提供**演示脚本**（页面路径 + 操作步骤 + 预期结果），你按脚本走查。

- 验收发现问题 → 记入缺陷清单（严重度/复现步骤/期望）→ 修复 → 回归。
- 最终交付报告含：完成度、关键决策、验证证据、已知限制、待办，以及主线完成率。
